# Rift Manager

2014~2026년 실제 리그·팀·선수 데이터로 즐기는 e스포츠 구단 운영 게임입니다. 설치 없이 브라우저에서 실행됩니다.

비공식 팬 프로젝트이며 Riot Games와 무관합니다. 자세한 고지는 [ASSETS.md](ASSETS.md)를 참고하세요.

## 실행

```bash
node tools/serve.mjs
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. (`python -m http.server 8765`로도 됩니다.)

## 주요 기능

- **시작**: 연도 선택(2014~2026) → 기존 팀 선택(전력 별점 표시) 또는 구단 창단(2부 리그에서 시작)
- **경기**: 밴픽(조합 성향·저격 밴·집중 라인) → 맵 위 실시간 중계 → 결과. 정규 시즌은 단판, 플레이오프는 3전 2선승, 결승·국제전 토너먼트·승강전은 5전 3선승
- **선수 능력치 10종**: 라인전, 메카닉, 한타, 운영 지능, 시야 장악, 골드 수급, 안정감, 챔피언 폭, 클러치, 팀워크
- **감독**: 실제 감독 명단. 전술·밴픽·육성·동기부여 능력과 특성(선수 능력치 보정, 성장 속도 등)이 팀에 반영되고, 교체 선임 가능
- **유스**: 스카우트를 보내 가상의 유망주를 발굴하고 아카데미에서 키워 1군으로 승격
- **수익 활동**: 스폰서 계약 선택(안정형·성과형·도전형), 굿즈, 경기 입장 수익, 콘텐츠 촬영, 팬미팅
- **운영**: 추천 영입과 원클릭 계약, 재계약, 훈련, 시설 투자, 이사회 목표, 승강전, MSI, 월드 챔피언십

## 데이터

- 리그·팀·선수·감독·경기 기록: [Leaguepedia](https://lol.fandom.com) (CC BY-SA 3.0)
- 능력치는 공식 수치가 아닙니다. 리그 기록(KDA·CS·승률·챔피언 폭)과 국제전 성적으로 종합 능력을 계산하고, `tools/ref/legends.csv`의 전성기 프로필로 항목별 강약을 조정한 추정치입니다.
- 위키에 2부 리그 기록이 없는 지역·연도는 가상 팀으로 채웁니다.

### 데이터 다시 만들기

```bash
node tools/01_tournaments.mjs   # 대회 목록
node tools/02_fetch.mjs         # 로스터·경기 기록 (요청 제한 때문에 오래 걸림)
node tools/02b_intl.mjs         # 국제전 기록
node tools/03_build.mjs         # data/*.js 생성
node tools/export_players.mjs   # 선수명단.csv 내보내기
```

수집한 원자료는 `tools/cache/`에 저장되며 저장소에는 포함하지 않습니다.

## 점검 스크립트

```bash
node tools/sim_test.mjs 30            # 경기 엔진 밸런스 (경기 시간·킬·승률)
node tools/season_test.mjs 2016 2     # 2016년부터 2시즌 자동 진행
```

## 구조

| 경로 | 내용 |
|---|---|
| `js/core.js` | 공통 상수, 능력치 정의, 조합 상성 |
| `js/engine.js` | 경기 시뮬레이션 엔진 |
| `js/world.js` | 새 게임, 일정, 리그·플레이오프·국제전 |
| `js/sim.js` | 경기 실행과 결과 반영 |
| `js/manage.js` | 이적, 계약, 성장, 시즌 전환 |
| `js/staff.js` | 감독, 수익 활동 |
| `js/youth.js` | 유스 발굴과 아카데미 |
| `js/view.js`, `js/broadcast.js`, `js/combat-vfx.js` | 경기 화면과 중계 연출 |
| `js/ui.js` | 운영 화면 |
| `tools/` | 데이터 수집·변환, 테스트 |
